# Agent Note: 在 setup 中提供可选的 Claude Code 状态栏

Status: implemented

[English](2026-10-14-optional-claude-statusline.md) | 中文

## 问题

个人状态栏命令依赖本地脚本和插件路径，难以复用。其 transcript 扫描重复推导当前 Claude Code 已直接提供的会话状态。setup 流程替换唯一的 statusLine 命令时，还可能抹掉其他状态栏工具的配置，或让它无法获得 stdin 输入。

## 决策

[setup-demon-skills](../../../../skills/agent/setup-demon-skills/SKILL.md) 仅在运行 setup 的 agent 是 Claude Code 时提供状态栏选项，其他运行环境跳过。[可选配置 reference](../../../../skills/agent/setup-demon-skills/references/statusline.md)负责检查、批准、组合及恢复流程，渲染器和安装器以脚本随技能分发。配置状态栏需在仓库脚手架之外单独获得批准，安装 skill pack 仍由用户决定。

渲染器读取当前 [Claude Code 输入数据](https://code.claude.com/docs/en/statusline)：第一行显示目录、模型、实时 effort 和会话名称；第二行显示上下文使用比例、容量和估算剩余 token，用方括号包住的二十格占用条区分实心填充与阴影空轨道，同时显示会话累计运行时长及可用的五小时和每周额度。整段 Context 随使用比例增加，从浅绿经深黄逐渐变为红色；空轨道保持中性弱化显示。五小时额度提供重置时间时显示倒计时，到期后省略。缺失且没有可保留测量结果的值不显示，标签中的控制字符被移除；Ponytail 激活时添加标记，无需依赖插件路径。对这份输入契约无需扫描 transcript。

按会话隔离的数值缓存区分暂缺测量和有效零值。Claude Code 在压缩后清空 `current_usage`，直到下一次 API 响应；保留上次上下文快照可避免误显示零值，`(last)` 则标明旧测量及 token 估算。运行时长缺失时也可保留上次测量。额度快照仅在重置时间尚未到期时短暂保留。有效下降和零值立即更新显示；完整测量替换快照。百分比存在但容量缺失时保留上次完整快照，且不延长其有效期，避免将不同时刻的测量拼成估算。模型或容量变化使不兼容的上下文失效。身份字段始终使用实时输入。[配置 reference](../../../../skills/agent/setup-demon-skills/references/statusline.md)负责保留期限和缓存位置。

已有状态栏保持原样，直到用户选择组合或替换。组合模式用明确选择的 shell 向原命令重放同一份 JSON 字节，在独立行中保留其输出，并将等待时间限制为两秒。已有边距和刷新间隔保留。组合保持原有 Vim 模式显示设置；替换恢复原生指示，因为该渲染器不绘制它。安装器记录原始与安装后的配置，并备份设置。待完成操作保留修改前和目标状态栏对象，以及原有恢复记录，使中断安装或恢复后重试能够识别任一写入边界，同时保留原始命令。恢复中断操作要求当前设置匹配其中一个记录对象；其他值会停止并等待检查。恢复也检查相同的配置归属，保留无关设置。

## 备选方案

- **配置所有 agent 运行环境。** 状态栏输入和设置属于 Claude Code；其他运行环境无需提示或适配器。
- **创建独立的状态栏 skill。** 用户要求的入口是 setup 中的可选提示；按需加载的 reference 可保留一份复用流程，无需新增发现入口。
- **串联共享 stdin 的命令。** 第一个渲染器可能读完全部输入；重放字节让每个渲染器都收到完整数据。
- **默认覆盖已有命令。** 保留原命令，并询问是否组合或替换，使其他状态栏工具仍由用户控制。
- **将所有零值视为缺失，或合并整份旧输入。** 重置和压缩后可能出现有效零值及下降；复用身份字段会掩盖实时修改。仅保留暂缺的资源测量，并明确标记为上次测量。

## 后果

- 只有选择该状态栏的用户需要 Python 3。配置路径在安装时解析，不分发个人脚本或插件路径。
- 组合可能重复原工具已显示的字段。命令配置无效、原命令失败或过慢时省略其输出，Demon 行继续显示；组合包装器和恢复都不承诺合并外部并发编辑。
- [隔离验收检查](../../../../skills/agent/setup-demon-skills/scripts/test-statusline.py)覆盖实时字段、连续暂缺测量、会话隔离、有效零值和下降、额度到期、缓存故障、输入重放、显示选项保留、重复安装、恢复、中断写入后的恢复、无效组合配置及外部编辑后的拒绝。真实终端渲染和 shell 选择在获批安装时验证。
