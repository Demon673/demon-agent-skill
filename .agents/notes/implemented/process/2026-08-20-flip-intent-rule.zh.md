# Agent Note: 把意图规则从许可翻转为门槛

Status: implemented

[English](2026-08-20-flip-intent-rule.md) | 中文

## 问题

原 standing order 写的是「仅当不澄清就会出错时才问一个澄清问题」——许可式默认。某次会话在讨论阶段（「看看应该怎么整合」）被执行了一个大改动，因为长会话的执行惯性压过了这条弱门。

## 决策

把根 AGENTS.md 那一行改写为门槛：只在明确的执行信号与确认的范围下动手；否则先问一个澄清问题。更完整的 confirm-intent 协议 skill 暂时搁置，等一行翻转被证明不够再说。

## 备选方案

- **现在就加 confirm-intent skill。** 暂否决：规则本来就在，失败出在默认值的极性上，所以先翻转这一行再观察。
- **保留旧措辞。** 否决：许可式默认在执行惯性下会失效。

## 后果

- 默认值现在是「除非明确被告知执行，否则先问」；讨论与分析请求永远不授权写入。
- 改动的那一行就是 standing order 本身；没有 skill 或其他文件承载这条规则。
