# Distilled prose examples

Use these examples to identify the governing principle, not as text templates. "Balanced" preserves every load-bearing proposition with the least explanation needed at that location.

## Preserve every factual clause

**Original:** "The linker flattens each skill directory name into the install directory, so two skills in different categories must not share a name."

**Over-trimmed:** "Skill names must be unique."

**Balanced:** "The linker flattens skill directory names, so two skills in different categories must not share a name."

The over-trim dropped the *why* (flat install), which is the fact that prevents a maintainer from "fixing" the rule later.

## Explicit skill scope is functional

**Over-trimmed:** "Read the sources and use judgment."

**Balanced:** "This skill is guidance, not a complete checklist. Use judgment beyond the named checks; documented requirements still apply."

Keep the explicit limitation because it changes how an agent applies the workflow. Trim repeated persuasion, not the guardrail.

## A description is a pointer

**Weak:** "Helps with documentation."

**Balanced:** "Use when writing, moving, or auditing documentation — choosing hierarchy and detail, or deciding where a fact belongs."

Front-load the trigger ("Use when writing, moving, or auditing"), list one branch per distinct case, and drop identity the body carries.

## Preserve ownership and timing

**Over-trimmed:** "Pairs update together."

**Balanced:** "Editing either side of a bilingual pair obligates the counterpart in the same change; review owns parity."

The over-trim lost the obligation's trigger (edit either side) and the boundary between machine checks and human review.

## Remove derivation, keep the contract

**Original:** "First I checked where the rule lived, then I decided README was the owner, so the rule goes in README."

**Balanced:** "The rule's home is README; link it from elsewhere."

The derivation path is session narration; the placement decision is the durable fact.
