# Decisions

## Use Existing Skills As References, Not Direct Dependencies

- Statement: Existing Agent skills should be used as design references, not installed as direct dependencies by default; prioritize local custom skills that fit the user's working style.
  Scope: current-workspace
  Source: user-confirmed 2026-06-15
  Status: active
  Applies when: designing, creating, or improving the user's personal Agent skill stack
  Does not apply when: the user explicitly asks to install or depend on an external skill
  Rationale: The user wants to learn from mature public skill patterns while keeping the actual workflow local, controllable, and tailored to their own use.
  Rejected alternatives: directly installing public skills as the default path
