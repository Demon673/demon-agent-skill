# 事故复盘

[English](README.md) | 中文

事故复盘：一个 bug 到达了它本不该到达的地方（真实用户、已合并的 PR、已发布的版本），有价值的部分是*为什么流程让它溜了过去*，而不是那一行修复。

事故复盘不是 [Agent Note](../../.agents/notes/README.md)（后者记录一个深思熟虑的设计决策及其被否决的备选方案，或提出未来工作）。它是一个回溯式的失败记录：坏在哪里、机制是什么、为什么每道安全网都漏掉了它，以及为了让同类 bug 下次大声失败而新增的具体护栏。

当一个 bug **隐蔽**（机制不明显，细心的工程师也得费力重新推导）、**系统性**（它溜走的原因是校验、工具或约定上的缺口，而非一次性笔误）、且**重新发现代价高**（它耗费了真实的调试时间，且还会再次耗费）时，就写一份。把事故复盘所催生的护栏（校验、`AGENTS.md` 规则、Agent Note）链接进去。

每份事故复盘都以**执行摘要**开头：一段忙碌读者三十秒能读完的短段落——坏在哪里、用平实语言说明根因、为什么溜走、以及可复用的教训——之后再展开详细的摘要 / 时间线 / 根因 / 护栏各节。
