# Triage 标签

[English](triage-labels.md) | 中文

skills 以五个规范 triage（分诊）角色说话。本文件把这些角色映射到本仓库 issue tracker 实际使用的 label 字符串。

| mattpocock/skills 中的 label | 本仓库 tracker 中的 label | 含义 |
| ---------------------------- | ------------------------- | ---- |
| `needs-triage`               | `needs-triage`            | 维护者需要评估这个 issue |
| `needs-info`                 | `needs-info`              | 等待报告者补充信息 |
| `ready-for-agent`            | `ready-for-agent`         | 规格完整，可派给 AFK agent |
| `ready-for-human`            | `ready-for-human`         | 需要人类实现 |
| `wontfix`                    | `wontfix`                 | 不予处理 |

当某个 skill 提到角色（例如"应用 AFK-ready triage label"），使用本表对应的 label 字符串。

编辑右列以匹配你实际使用的词汇。
